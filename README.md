# SmirnovaP
# 🏋️‍♂️ Training Planner

**Автор:** Полина Смирнова
**Язык:** Python 3

## Описание проекта

Графическое приложение для планирования и ведения дневника тренировок.
Позволяет добавлять тренировки с указанием даты, типа и длительности. Данные сохраняются в формате JSON.
Встроены фильтры для быстрого поиска и проверка корректности ввода.

## Возможности

*   **Добавление тренировок:** Ввод даты (ДД.ММ.ГГГГ), типа (Кардио/Сила/Гибкость) и длительности.
*   **Фильтрация:** Поиск по типу тренировки и/или конкретной дате.
*   **Сохранение/Загрузка:** Работа с файлом `data.json`.
*   **Валидация:** Проверка формата даты и числового значения длительности.
*   **Контроль версий:** Проект готов к работе с Git.

## Технологии

*   **Python 3.13
*   **Tkinter** — стандартная библиотека для создания GUI.
*   **JSON** — хранение данных.
*   **Git** — система контроля версий.

## Как запустить

1.  Убедитесь, что у вас установлен Python 3.
2.  Склонируйте репозиторий.
3.  Запустите приложение из корня проекта:
    ```bash
    python main.py
    ```
4.  Для работы с данными используйте кнопки «Сохранить в JSON» и «Загрузить из JSON».
